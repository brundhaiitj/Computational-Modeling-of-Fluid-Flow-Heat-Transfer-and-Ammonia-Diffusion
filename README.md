# Computational Modeling of Fluid Flow Heat Transfer and Ammonia Diffusion
## Introduction:
This repository contains a set of Python-based numerical simulations developed to study fundamental transport phenomena including fluid flow,heat transfer, and ammonia evaporation diffusion.

The models are inspired by Computational Fluid Dynamics (CFD) concepts and focus on physically consistent analysis using thermodynamics,fluid mechanics, and mass transfer principles.These projects focus on "Monozukuri" (technology-driven manufacturing) by utilizing engineering expertise to solve complex environmental and industrial problems. These simulations are relevant to industrial thermal systems and ammonia safety analysis.

### What is in this Repository
This repository contains three main simulation projects:  
1. **Numerical Simulation of Laminar Flow & Heat Transfer in a 2D Channel:** Computes laminar velocity profiles and temperature distribution in a 2D channel.  
2. **Smart Thermal-Fluid Process Monitoring, Optimization & Quality Control System:** Analyzes pressure drop, heat transfer, outlet temperature, and applies Statistical Process Control (SPC) for monitoring.  
3. **Ammonia Evaporation & Diffusion Simulation:** Models ammonia evaporation from a liquid pool and its diffusion in air over time using numerical methods.

### What Can Be Found Here
- Python scripts for each simulation project.  
- Sample **plots and visualizations** of velocity, temperature, pressure drop, and ammonia concentration.  
- Step-by-step computational approaches to **fluid dynamics, heat transfer, and mass diffusion** phenomena.  

### How to Open and Run in Google Colab
1. Open [Google Colab](https://colab.research.google.com/).  
2. Click **File → Upload Notebook** or **File → Open Notebook → GitHub**, and paste the repository URL.  
3. Upload the respective Python script (e.g., `channel_flow.py`, `pipe_flow_spc.py`, `ammonia_diffusion.py`) or open directly from GitHub.  
4. Run each code cell sequentially to execute simulations and generate plots.  
5. Modify parameters (grid size, velocity, temperature, diffusion coefficient, etc.) as needed for experimentation.
